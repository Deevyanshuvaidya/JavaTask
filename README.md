# 🔍 Searching Algorithms

## Binary Search

```text
Binarysearch.java
```

Demonstrates the implementation of the **Binary Search** algorithm.

Binary Search works by repeatedly dividing a sorted search range into smaller sections.

Conceptually:

```text
Sorted Array
     │
     ▼
Find Middle Element
     │
     ├── Target Smaller
     │       ↓
     │   Search Left
     │
     └── Target Larger
             ↓
         Search Right
```

The average time complexity of binary search is:

```text
O(log n)
```

when the input is sorted and the standard binary-search approach is used.

---

# 🔄 Sorting Algorithms

## Bubble Sort

```text
Bubblesort.java
```

Demonstrates the **Bubble Sort** algorithm.

Bubble Sort repeatedly compares adjacent elements and swaps them when they are in the wrong order.

Conceptually:

```text
[5, 2, 8, 1]

Compare 5 and 2
      ↓
Swap

Compare 5 and 8
      ↓
No Swap

Compare 8 and 1
      ↓
Swap

Continue until sorted
```

Typical time complexity:

```text
Worst Case: O(n²)
```

Bubble Sort is primarily useful for learning sorting concepts rather than for large-scale production applications.
